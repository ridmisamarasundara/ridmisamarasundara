## 🚀 Featured Projects

### 🎪 RentoraX: Event Rental Platform
A full-stack rental platform for event equipment with separate customer and administrator experiences.

- Built REST APIs for registration, login, items, bookings, approvals and dashboard statistics
- Secure authentication with Spring Security and BCrypt, plus CORS protection
- Booking lifecycle (Pending, Active, Past) with admin approve/reject flows and notifications
- Admin dashboard with revenue and inventory overview, earnings charts and full CRUD inventory

`Java 21` `Spring Boot` `Spring Security` `MongoDB` `React` `Tailwind CSS` `Postman`

### 🌾 AgriLink: Mobile Marketplace App
A mobile marketplace connecting farmers, vendors and buyers.

- RESTful APIs for three user roles (Farmers, Vendors, Buyers) with inventory synchronisation
- Real-time buyer and vendor chat using Socket.io
- Shopping cart, order lifecycle management and live order tracking notifications
- Authentication, dynamic product filtering, ratings and reviews, and payment gateway integration

`React Native` `Node.js` `Express.js` `Socket.io` `REST APIs`
